Gaspar

Manual de Instalação e Desinstalação (Drop-In)

Bem-vindo ao Gaspar. Este sistema foi desenhado para ter uma instalação "Drop-In", o que significa que não é necessário utilizar o terminal (SSH) ou rodar comandos complexos no servidor. Siga o passo a passo abaixo para colocar o sistema no ar.

🚀 Requisitos do Servidor

  • Servidor Web (Apache, Nginx, LiteSpeed, etc.)
  • PHP 8.2 ou superior
  • Banco de Dados MySQL
  • Extensões PHP padrão do Laravel (BCMath, Ctype, Fileinfo, JSON, Mbstring, OpenSSL, PDO, Tokenizer, XML)

📥 1. Instalação do Sistema (Primeiro Uso)

Passo 1: Upload e Extração

  1. Faça o upload do arquivo gaspar.zip para o seu servidor web (ex: dentro da pasta public_html, www ou em um subdomínio).
  2. Descompacte o arquivo .zip. Ele irá extrair todos os arquivos do projeto.

Passo 2: Permissões de Escrita

O servidor web precisará de permissão para escrever e criar arquivos. Garanta que as pastas storage e bootstrap/cache possuam permissão 775.

Passo 3: Acesso e Assistente Web

  1. Abra o seu navegador e acesse a URL correspondente à pasta onde você extraiu o sistema.
    Exemplo: http://seusite.com.br/gaspar/public
  2. O sistema detectará automaticamente que é o primeiro acesso e redirecionará você para o Assistente de Instalação.

Passo 4: Configuração

  1. Banco de Dados MySQL: Insira os dados de conexão (Host, Porta, Usuário, Senha e Nome do Banco). Se o banco não existir e seu usuário tiver privilégios, o sistema tentará criá-lo automaticamente.
  2. Administrador: Defina o Nome, E-mail e Senha do primeiro usuário Administrador do sistema.
  3. Clique em Instalar Gaspar.

O que acontece por baixo dos panos: O sistema gera as chaves, cria o arquivo .env, constrói todas as tabelas do banco de dados e cria a trava de segurança (installed.txt).

🗑️ 2. Como Desinstalar o Sistema (Wipe Completo)

Se você precisar formatar o sistema, limpar todos os dados de testes ou refazer a instalação do zero, use o módulo de desinstalação seguro.

  1. Navegue até a URL de desinstalação: http://seusite.com.br/gaspar/public/desinstalar (ajuste a URL conforme o seu domínio).
  2. Confirme a ação na tela.
  3. Você será redirecionado de volta para o Assistente de Instalação com o sistema zerado e limpo.
⚠️ Dica Importante sobre Segurança:

Nunca deixe arquivos .zip de backup largados na pasta pública do servidor. Após realizar a extração e verificar que o sistema funciona, apague o arquivo gaspar.zip original do servidor para poupar espaço e manter a segurança.
